# Better Clip

A minimal, glass-inspired, native-feeling local clipboard utility for Windows built with C#, .NET 10, and WinUI 3.

## Features
- **Instant Access:** Summoned via global shortcut (`Ctrl + Space`).
- **Glass Aesthetic:** Translucent surfaces and background blur.
- **Automatic Organization:** Text, Images, Links, Files, and Video categories.
- **24-Hour Retention:** Automatic cleanup with pinned-item protection.
- **Privacy First:** 100% local operation with SQLite and FTS5.
